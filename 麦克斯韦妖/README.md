# 麦克斯韦妖

一个围绕“手动转移物性”的横版解谜游戏项目。

## 当前核心

- 物品不能凭空复制属性；属性只能在直接接触的物品之间手动转移。
- 每条物性轴都有 `-1 / 0 / +1` 三个状态。
- 转移是移动一个单位，不是复制：源物品向负方向移动，目标物品向正方向移动。
- 反应过程不是独立属性，而是由属性组合产生：
  - `烫 + 可燃 → 燃烧`
  - `冷 + 可冻结 → 结冰`
- 当前只保留五条轴：温度、燃烧性、冻结性、重量、形变。

## 项目结构

```text
麦克斯韦妖/
├─ assets/          图片、音频和其他资源
├─ docs/            设计文档与规则表
├─ levels/          关卡草图和关卡数据
├─ src/             引擎无关的规则模型
├─ tests/            规则测试
└─ tools/            设计辅助工具
```

项目暂时不绑定具体游戏引擎。先用小型参考模型验证物性转移和接触反应，再决定正式引擎与表现层。

# 麦克斯韦妖的燃烧水

一个围绕“手动转移物性”的横版解谜游戏项目。

## 当前核心

- 物品不能凭空复制属性；属性只能在直接接触的物品之间手动转移。
- 每条物性轴都有 `-1 / 0 / +1` 三个状态。
- 转移是移动一个单位，不是复制：源物品向负方向移动，目标物品向正方向移动。
- 反应过程不是独立属性，而是由属性组合产生：
  - `烫 + 可燃 → 燃烧`
  - `冷 + 可冻结 → 结冰`
- 当前只保留五条轴：温度、燃烧性、冻结性、重量、形变。

## 当前实现

- Godot 4.7 网页试玩工程位于 `godot/`。
- GitHub Pages 导出位于仓库根目录的 `maxwell-demon/`。
- 已有一个全验证场景、四类候选通关路线、图鉴与网页攻略。
- 当前为持续黑盒测试中的公开测试版；测试结论与遗留项记录在 `docs/全验证Demo.md`。

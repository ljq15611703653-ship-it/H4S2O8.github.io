# 《麦克斯韦妖的燃烧水》攻略（剧透）

> 本文会直接说明全验证 Demo 的规则与通关路线。想自己实验时请先不要看。

## 操作

- `A / D`：移动
- `空格`：跳跃
- `E`：抓取 / 放下
- `R`：使用锤子，或建立树脂连接
- `1—5`：依次转移温度、燃烧性、冻结性、重量、形变的正单位
- `Ctrl + 数字`：转移负单位
- `Shift + 数字`：让接触物成为来源、手中物成为接收者
- `T`：重置
- `C`：规则图鉴

## 先记住三件事

1. 转移必须让手中物与目标真实接触；来源失去一单位，接收者获得一单位。
2. 从普通物提取正单位，来源会变成相反的负物性。例如从普通物提取“重”，来源会变轻。
3. 门只检查高处门区内是否还有有效重物。把门前铁块移开后，妖怪还要亲自进入出口。

## 路线一：直接转移重性

1. 把普通接收块沿货运斜坡送进门前侧槽，让它与门前重铁块接触。
2. 确保接收块落在侧槽而不是门槛正中。
3. 使用反向重量转移：`Shift + 4`。
4. 铁块失去重性；接收块变重并立即脱手，但侧槽中的新重物不会挡门。
5. 进入出口。

## 路线二：轻物—树脂—重物链

1. 借助弹性跳板进入捕轻笼，取得轻壳。
2. 让黏塑树脂接触轻壳，手持树脂按 `R`，建立第一段连接。
3. 再让树脂接触门前重铁块，按 `R` 建立第二段连接。
4. 轻壳持续连接时，铁块的有效重量降为普通，可以被推动离开门区。
5. 进入出口。

## 路线三：燃烧木支撑

1. 把可燃引火木块送到木支撑旁。
2. 从一个普通物中提取“烫”并转给引火木块；普通来源同时变冷。
3. 引火木块具有“烫 + 可燃”，会立即燃烧，并点燃接触的木支撑。
4. 木支撑持续燃烧后烧穿，门槛倾斜；铁块受重力滑出门区。
5. 进入出口。

## 路线四：浴缸水结冰支撑

1. 用锤子打碎浴缸右侧玻璃塞，让网格水体改变轮廓、泄出并沿斜坡流到高处支撑区。
2. 水本身可冻结。让水接收“冷”单位；提供冷单位的普通来源会变烫。
3. “冷 + 可冻结”使整团同状态水结冰，流体碰撞单元变成固体冰粒。
4. 冰在支撑区顶起门槛，铁块滑出门区。
5. 进入出口。

## 制作流动的火

1. 先打开浴缸出口，让水处于可流动区域。
2. 让水从普通物接收一单位可燃性：水变可燃，来源变成灭火物。
3. 再让水从另一个普通物接收一单位温度：水变烫，来源变冷。
4. 水满足“烫 + 可燃”，立即燃烧；它仍是可变形液体，会继续受重力流动、分裂/汇合，并点燃接触的可燃物。

## 常见失败

- 手中物没有碰到目标：不会转移。
- 把新重物制造在门槛正中：它会继续挡门。
- 物品变重、冷、烫、燃烧或结冰：妖怪会立即脱手。
- 普通水接触燃烧物：会暂时灭火并被加热；水离开后，若原物仍是“烫 + 可燃”，会重新燃烧。
- 状态不同的液体不会直接汇合；先发生冷热等接触反应，结果完全相同时才会合并为一份连通液体。

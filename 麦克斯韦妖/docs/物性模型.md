# 物性模型

## 三态轴

每条物性轴有 `-1 / 0 / +1` 三个值。转移不是复制，而是移动一个单位：源物品向负方向移动，目标物品向正方向移动。

```text
可燃（+1） → 普通（0） → 灭火（-1）
可冻结（+1） → 不可冻结（0） → 阻止结冰（-1）
```

给负态物品加入一个正向单位，它会回到普通态；从普通态继续抽取，则会进入负态。

## 当前轴

| 轴 | -1 | 0 | +1 |
|---|---|---|---|
| 温度 | 冷 | 常温 | 烫 |
| 燃烧性 | 灭火 | 普通 | 可燃 |
| 冻结性 | 阻止结冰 | 不可冻结 | 可冻结 |
| 重量 | 轻 | 正常 | 重 |
| 形变 | 黏塑性 | 普通 | 弹性 |

冷和烫是同一条温度轴的两个方向。普通石头可以是“不可冻结”，它接触冷会变冷，但不会结冰；只有“阻止结冰”才会主动让冰解冻。
